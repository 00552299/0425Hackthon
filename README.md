# AI-Augmented WebXR Platform for Lexical Acquisition

## Abstract

This repository contains the source code for a specialized WebXR application developed for the Spatial Shanghai 2026 Agent Engineering 24-hour Hackathon under the Higher Education track. The project addresses the theme of "Hacking the University" by fundamentally reimagining how university students prepare for standardized English proficiency examinations, specifically IELTS and TOEFL. By synthesizing AI pedagogical agents with interactive 3D visualization, the system transforms passive vocabulary memorization into an active, multi-sensory experience involving spatial, auditory, and verbal engagement.

## Pedagogical Approach

Traditional language learning in higher education often relies on rote memorization and two-dimensional flashcards. This platform disrupts that paradigm through:

- Spatial Memory Integration: Utilizing 3D models generated by Tripo AI to represent abstract concepts, allowing students to leverage the Method of Loci for improved word retention.
- AI-Driven Feedback: Integrating intelligent agents that facilitate real-time speaking and listening drills tailored to the student progress.
- Immersive Interaction: Providing a browser-based XR environment where users manipulate objects to trigger linguistic data, bridging the gap between digital content and physical intuition.

## Core Features

- AI Agent Tutoring: Provides contextualized listening exercises and evaluates spoken input for pronunciation and grammatical accuracy.
- Automated 3D Asset Generation: Leverages Tripo AI to rapidly generate high-fidelity 3D models corresponding to core IELTS/TOEFL vocabulary.
- Seamless WebXR Integration: Enables immersive learning across desktops, mobile devices, and VR hardware such as Meta Quest without requiring external software.
- Multi-Sensory Feedback: Synchronizes visual cues with high-quality audio and AI-generated prompts to reinforce learning pathways.

## Technical Specifications

- 3D Generation: Tripo AI for rapid 3D asset creation based on vocabulary keywords.
- Frontend: Built with Three.js and the WebXR Device API for high-performance 3D rendering.
- Backend: Developed using Node.js and Express to manage user data and orchestrate AI API calls.
- Communication: Utilizes WebSockets for low-latency interactions during AI-led speaking exercises.

## Installation and Setup

Ensure that Node.js (v18 or higher) is installed on your system.

1. Install project-wide dependencies:
npm install

2. Install client-side dependencies:
npm --workspace client install

3. Install server-side dependencies:
npm --workspace server install

## Running the Application

To operate the platform, both the backend and frontend services must be active.

1. Start the backend server:
npm run dev:server
The service will initialize at http://localhost:3000.

2. Start the frontend client:
npm run dev:client
The interface will be accessible at http://localhost:5173.

## Interaction Mechanics (Meta Quest Controllers)

The application is optimized for Meta Quest controllers to provide an intuitive learning experience:

- Model Inspection (Drag/Rotate): Use the primary trigger or grip button on the Meta Quest controller to grab and rotate 3D models. This spatial manipulation reinforces the cognitive link between the visual object and the linguistic term.
- Interaction (Click): Point and click on specific models or UI elements using the controller rays to trigger audio definitions, synonyms, or to initiate a verbal response prompt from the AI agent.
